# NEA 

## Dungeon crawl roguelike project made for the AQA NEA (A-Levels). 

Follows a grid like room structure on a 2-D platformer, using pygame as the game engine.

Includes simple combat where enemies gravitate towards you, saving functionality, and procedural generation of grid structure.

This project was completed and examined on 2022, and has been ported from my school github to my main on 2023. 

## Movement
Uses standard WASD movement

W - up
A - left
S - down
D - right

## Attack
Uses arrow keys as attack buttons.
